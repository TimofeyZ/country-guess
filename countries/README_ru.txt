ПАПКА COUNTRIES — 100 СТРАН

Структура образца сохранена: одна папка на страну, фотографии именуются как 0 (1).jpg, 0 (2).jpg и т. д. Исходные фотографии из архива не изменены.

ВАЖНО: в этой среде не удалось напрямую скачать двоичные изображения с внешних сайтов. Поэтому для 91 новых стран и пустой папки Egypt добавлен загрузчик, который скачивает настоящие фотографии из Wikimedia Commons. После загрузки архива на компьютер с интернетом нужно:

1. Распаковать ZIP.
2. Открыть папку «countries — копия».
3. Дважды нажать «СКАЧАТЬ_ФОТОГРАФИИ.bat».
4. Дождаться завершения загрузки. Окно можно закрыть после сообщения о завершении.

Нужен установленный Python 3. Отдельные библиотеки устанавливать не требуется. Фотографии сохраняются в папки соответствующих стран, размер превью обычно до 1000 пикселей по ширине. Скрипт старается загрузить до 4 фотографий на страну, по двум достопримечательностям; фактическое число может быть меньше, если по запросу не нашлось подходящих файлов.

Источники и атрибуция: фотографии берутся из Wikimedia Commons. По завершении в photo_credits.csv будут страницы исходных файлов, авторы и указанные лицензии. Условия повторного использования каждой фотографии нужно проверять по её странице на Commons.

Повторный запуск безопасен: если в папке уже есть 4 или больше изображений, скрипт её не меняет; уже скачанные файлы не удаляются.
